This document lists the weather conditions used by QWeather APIs and their corresponding codes and icons.

## Icons {#icons}

QWeather provides an open-source SVG weather icon set with icon font support. You can embed the icons in websites and apps or customize them using the available source files.

The `icon` field in API responses usually maps to a weather icon. Alert and moon phase icons are also available for their corresponding API fields.

👉 Visit **[QWeather Icons](https://icons.qweather.com/en/)**
