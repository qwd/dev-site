This document lists all weather conditions used by QWeather APIs, including their corresponding codes and icons.

## Icons {#icons}

We provide a set of open-source weather icons in SVG format, with support for icon fonts. You can easily embed them in websites or apps. The original design files are also available, allowing developers to customize the icons as needed.

The `icon` field in API responses usually maps to a weather icon. Icons for alerts and moon phases are also available and can be mapped to the corresponding fields in API responses.

👉 Visit **[QWeather Icons](https://icons.qweather.com/en/)**
