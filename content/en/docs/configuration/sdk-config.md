QWeather also provides iOS and Android SDKs to make it easier to integrate weather services. Installation, configuration, and usage documentation for the mobile SDKs is maintained in the corresponding GitHub repositories. Choose your development platform and visit GitHub for the latest configuration instructions, example code, and release notes:

- [iOS SDK configuration](https://github.com/qwd/qweather-ios-sdk/blob/main/README.md)
- [Android SDK configuration](https://github.com/qwd/qweather-android-sdk/blob/main/README.md)
