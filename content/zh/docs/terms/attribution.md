根据我们的[开发者许可协议](https://www.qweather.com/terms/developers-eula)和数据提供方的要求，如果在你的产品中使用了和风天气开发者服务，你需要按照下列方式注明来源（或称为“归因”）和必要的数据源信息。

## 注明来源 {#attribution-requirements}

当你在应用、网站或任何产品中使用了和风天气开发者服务时，必须清晰、完整地显示如下归因信息：

- “和风天气” 或 “QWeather”
- API 响应 [`metadata.attributions`](/docs/resource/metadata/#attributions) 中的所有内容（如有），包括数据提供方的名称、声明、URL或其他内容，不得删减、改写。例如天气预警中，你需要注明发布机构和其声明等信息。


## 样式要求 {#display-guidelines}

我们没有明确的样式要求，但应该遵循以下要求：

- **展示位置：** 在展示相关数据的页面或视图中展示所有归因信息。
- **可见性：** 请保证归因信息的可见性，即字体样式、字号或颜色不应该过于难以辨认；如果无法添加可点击的链接，可以将 URL 以明文形式展示。
- **不易混淆：** 归因信息应与产品正文、广告等内容明确区分，不能使用户误以为数据源方为你的产品或广告提供背书。
- **非冒犯性：** 在归因信息的上下文中，不能出现冒犯性或容易引起反感或对和风天气和数据提供方产生负面影响的内容。

## 例外 {#exceptions}

如果你的产品运行于特殊设备，无法按上述要求显示归因信息，请联系我们以便确认适用的展示方式。
