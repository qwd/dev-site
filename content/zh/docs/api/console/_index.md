控制台 API 可以轻松的了解帐号的财物信息和请求量信息，你可以根据这些数据评估使用率或者建立财务预警。

出于安全考虑，所有凭据默认没有权限请求控制台API，你必须在凭据设置中启用控制台 API 才可以请求对应的数据。控制台 API 返回的数据均为上一个小时或更早时候，有可能与控制台网站中显示的不一致，请以 `asOf` 响应的时间为准。
